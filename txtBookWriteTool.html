txtBookWriteTool

一款用txt写作的小工具

软件特色：单文件运行，用简单的 txt 和文件夹结构灵活管理写作内容。



使用说明
  1. 请用 Edge 或 Chrome 浏览器，其他浏览器有待后续支持
  2. 选择一个本地文件夹作为书稿目录，其中 .txt/.md 文件自动按目录树管理
  3. 「编辑」模式 Markdown 编辑与预览；
    「大纲」模式拖动调序；
    「阅览」模式合并成一本书连续显示
  4. 文件名以 _ 开头（如 _灵感.txt）时被视为草稿，不参与阅览和 PDF 导出
  5. 可把文件夹或 .txt/.md 文件直接拖入窗口打开；
  6. 「继续上次」需浏览器授权：弹框里选 「每次访问都允许」，之后启动会自动静默恢复

txtBookWriteTool · 使用说明

张亮军　无锡·海岸城
www.zhangliangjun.cn

这是什么

txtBookWriteTool 是一款免费开源的本地写作工具：以普通文件夹为书稿目录，用 .txt / .md 按 Markdown 写作，可合并成书、导出 PDF / HTML / Markdown。

编号与排序

  • 文件编号：三位数字（举例：110.txt），新建文件在已有编号上自动 +10。
  • 文件夹编号：与文件统一排序，无编号的排最前。
  • 自动重新编号：所在文件夹统一重排，文字保留。
  • 自动命名：110.txt → 110-第一行文字.txt（超 16 字截断）。

草稿 / 素材

  • 名字以 _ 开头（兼容 [草稿]、draft-）即为草稿：可编辑可搜索，但不参与阅览导出；
  • 点隐藏文件按钮可快速切换此状态。

四种模式

  • 编辑：左写右预览，自动保存；
  • 预览：仅预览当前文件。
  • 阅览：全文件夹合并成书，左侧目录先文件名、再文内标题。
  • 大纲：卡片纵览全书，拖动调序/移入文件夹，编号自动重排。

写作辅助

  • 图片：粘贴/拖入自动存 assets 并插入，语法 ![](路径 =600x400 center)，宽高可只写一个；
  • 表格：表格内浮出工具条增删行列；
  • 调色盘：选色插入色值；
  • 全角空格：插入中文空格。
  • ◀/▶：按目录顺序切换文件（草稿除外）；
  • 搜索：全文查找，点结果跳转，Esc 或 ✕ 清空。
  • 替换：可选单文件或全项目 md/txt（含草稿需确认），替换前自动存「历史版本」。
  • 注释：<!--注释--> 仅编辑可见，阅览/PDF/导出 HTML 不显示（导出 MD 保留）。
  • 合并：Ctrl+点选多文件，内容并入第一个、其余删除；多选后拖动/删除/复制/隐藏按组操作。
  • 拆分：按光标/标题/关键词拆分，原文件存前半并保留原名，后续 base_2.txt、base_3.txt…（原文件排前）；目标名被占用时编号自动顺延、确认后创建；勾选「将文件移动到同名文件夹后再拆分」会先建与文件同名（不含扩展名）的文件夹并移入原文件，拆分产物全部集中其中；目录树可拖动，拖到项目名=移到根目录。

快捷键

  • 文字格式：Ctrl+B / Ctrl+I 粗体/斜体；Ctrl+K 插入链接；Alt+C 当前行加/去注释；Alt+T 插入当前日期时间；Ctrl+Shift+K 删除当前行；Ctrl+J 当前行与下一行合并（中文之间不加空格）。
  • 标题与列表：Ctrl+Shift+1~6 设为 H1~H6（再按取消）；Ctrl+[ / Ctrl+] 列表行减少/增加缩进；Alt+X 任务待办切换；Ctrl+Shift+` 插入代码块围栏；Enter 自动续接列表；Tab 插入两个空格。
  • 移动行块：Alt+↑ / Alt+↓ 上移/下移当前行；Alt+Shift+↓ 向下复制当前行。
  • 文件与模式：Ctrl+S 立即保存；Ctrl+Alt+→ / Ctrl+Alt+←（或 Alt+PageDown / Alt+PageUp）按目录顺序切下/上一个文件；Alt+1~4 依次为编辑/预览/大纲/阅览（已在编辑模式时再按 Alt+1 切换右侧预览显隐）；F2 重命名当前文件；Alt+N 新建 txt；Alt+O 打开文件夹；Alt+S 预览只显示标题与未完成待办；Ctrl+F 聚焦搜索框。

输出

  • 导出 PDF：阅览预览后点导出，打印目标选「另存为 PDF」。
  • 导出 MD：合并为一个 Markdown 下载（名带日期），可用 Typora 转 PDF。
  • 导出 HTML：单文件含左侧目录与自定义样式（名带日期），双击即可浏览器阅读。

回收站与历史

  • 删除/合并的文件进项目内 .trash，可恢复或清空；
  • 自动保存有变化时旧内容存 .history（按路径镜像），每文件留 20 版，可查看恢复；
  • 重命名/移动时历史跟随，恢复重名加「(恢复 n)」后缀；批量替换前自动留档。
  • 移入回收站历史保留；彻底删除/清空回收站才连历史清除、不可恢复，普通删除可找回。
  • .trash/.history 文件夹在工具内自动隐藏。
  • 建议定期复制整个项目文件夹备份。

设置加密密码

密码仅存于本次会话，关闭页面即清除；AES-256-GCM 加密。

解密预览

可编辑明文后点「更新加密块」重新加密替换原密文。

回收站

删除或合并的文件先移到项目内 .trash 目录，可恢复；清空后不可找回。

最近项目

点条目就在当前标签页打开；♡ 收藏后位置固定（不会被挤掉、也不会因使用次数变化），✕ 从列表移除；未收藏最多留 10 条。键盘：方向键选择、Enter 打开、Tab 切到 ♡/✕ 与按钮、Esc 关闭。
