txtBookWriteTool （一款用txt写作的小工具） · 使用说明

张亮军　无锡·海岸城
www.zhangliangjun.cn

这是什么

  • 这是一款用txt写作的小工具。单文件运行，小巧轻便。
  • 软件支持把电脑上的一个普通文件夹当作书稿目录，里面放 .txt / .md 文件，全部用 Markdown 语法写作。
  • 软件支持把目录下所有 .txt / .md 文件合并为一个文件，方便阅览和导出。
  • 软件支持用下划线_前缀来标记隐藏文件(比如 _灵感.txt)，方便管理素材资料。
  • 文件默认保存为 .txt 但按 Markdown 解析（方便在 Windows 资源管理器里预览）
  • 数据全部在本地文件夹，不联网、不上传。
  • 请使用新版 Edge 或 Chrome 浏览器打开；首次选择文件夹时在弹窗里点“允许”。

开始使用

  • 打开文件夹：选择书稿根目录。授权会被记住，下次打开页面自动加载；

编号与排序

  • 文件名用三位数字编号：110.txt、110-标题.txt。新建文件自动取当前目录下最大编号并 +10，留好未来文件的插入空位。
  • 文件夹也可以编号：重命名为 120-正文 后，文件和文件夹按 110、120、130 统一排序，可实现“序言 → 正文文件夹 → 后记”的穿插结构；不编号的文件夹固定排在最前。
  • 重新编号：先选中一个文件或文件夹，点该按钮，只对所在文件夹内的文件和带编号子文件夹统一重排为 110、120、130…，文字部分保留。
  • 自动命名：把 110.txt 改成 110-第一行文字.txt（超过 16 字截断）。

草稿 / 素材

  • 文件名或文件夹名以 _ 开头（也兼容 [草稿]、draft-）即为草稿：可正常编辑、搜索，但不参与阅览和导出；草稿文件夹内的全部内容都不输出。去掉下划线即恢复。
  • 快速隐藏：选中任意文件或文件夹点隐藏文件按钮，名称前会加上 _ ，不予输出（阅览/PDF/HTML/MD 均不含）；当选中已隐藏项目时按钮变成取消隐藏，再点恢复。

四种模式

  • 编辑：左边写 Markdown，右边实时预览；自动保存。
  • 预览：单独预览当前文件。
  • 阅览：把整个文件夹按顺序合并成一本书（顶部居中显示项目名），左侧目录先列文件名、再列该文件内的标题。
  • 大纲：以卡片纵览全书——文件夹是卷、文件是章节，卡片显示标题、摘要和字数；直接拖动卡片即可调整章节顺序，编号自动重排，拖到文件夹卡片中段可移入该文件夹。

写作辅助

  • 图片：直接粘贴或拖入即自动存入 assets 并插入；语法 ![](路径 =600x400 center)，可只写宽或高，对齐用 center/left/right。
  • 表格：插入表格对话框；光标在表格内时浮出工具条可增删行列。
  • 调色盘：选颜色确认后把色值插到光标处。
  • ◀ / ▶：按目录顺序快速切换上一个 / 下一个文件（草稿除外），编辑、预览、阅览模式下都可用。
  • 全角空格：在光标处插入一个中文全角空格（　），用于中文排版。
  • 插入注释：在光标处插入 <!--注释-->，占位文字自动选中可直接输入；HTML 注释只在编辑源码时可见，阅览、PDF、导出 HTML 中均不显示（导出 MD 原文保留）。
  • 替换：点「替换」在对话框中选择作用范围——仅当前文件，或整个项目的全部 md/txt 文件（草稿也包含，替换前需确认）。替换前的内容会自动存入「历史版本」，可随时恢复。
  • 搜索：顶栏搜索框在项目全部文件内容中查找，点结果跳到对应行，Esc 或 ✕ 清空。
  • 合并：Ctrl+点击多选文件（Esc 或“取消选择”清空），合并后内容写入第一个文件、其余删除。
  • 拆分：选中一个文件点「拆分」，可按指定级别的标题（#）或行首关键词拆成多个文件：统一命名为 xxx-split-0.txt、xxx-split-1.txt…（编号从 0 开始保证排序连续，原文件移入回收站可恢复）。适合把论文大纲拆开后逐章编写。
  • 目录树里可直接拖动文件/文件夹移动；拖到顶部项目名上等于移到根目录。

输出

  • 导出 PDF：点「阅览」标签进入成书预览；预览确认后点「导出 PDF」，打印窗口的「目标」务必选浏览器内置的「另存为 PDF」。
  • 导出 MD：按目录顺序合并为一个 Markdown 文件下载到下载文件夹（文件名带日期），可在 Typora 等编辑器中转 PDF。
  • 导出 HTML：单文件、含左侧目录和自定义样式（文件名带日期），正文标题下显示作者与日期，双击即可在浏览器阅读。

回收站与历史版本

  • 回收站：删除文件/文件夹、以及合并时被并入的文件，都会先移到项目内的 .trash 文件夹；点「回收站」可恢复、彻底删除单项或清空。
  • 历史版本：每次自动保存时若内容有变化，旧内容自动存入项目内的 .history（按文件路径镜像存储），每个文件保留最近 40 版；选中文件点「历史」可查看、恢复任意旧版（恢复前当前内容也会先存一版）。项目内批量替换前同样自动留档。
  • 重命名/移动时历史跟随：重命名文件或文件夹、跨目录拖拽移动时，.history 下对应的旧路径历史会自动迁移到新路径——旧版本不丢失，可继续叠加新版本。从回收站恢复时若遇重名自动加「(恢复 n)」后缀，历史目录也会跟随迁移。
  • 删除时历史清理：移入回收站时历史保留不动（便于恢复）；只有「彻底删除单项」或「清空回收站」时，才会连同 .history 下对应路径一并清除——与文件本身的生命周期对齐。
  • .trash 和 .history 在本工具中自动隐藏，不参与阅览和导出；在 Windows 资源管理器中可见，备份项目时一并复制即可。不再需要时删掉该目录即可。

注意

  • 「清空回收站」和「彻底删除」会一并清除对应历史版本，不可恢复；普通删除和合并都可在回收站找回（历史也保留）。重要书稿建议定期把整个项目文件夹复制备份。
