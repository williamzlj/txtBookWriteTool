这是什么

txtBookWriteTool 是一款免费开源的本地写作工具。它以一个普通文件夹作为书稿目录，用 .txt / .md 文件按 Markdown 语法写作，最终可合并成书、导出 PDF / HTML / Markdown。

编号与排序

  • 文件三位数字编号:（举例：110.txt），新建文件会在已有编号基础上自动+10。
  • 文件夹也可编号:，与文件统一排序，无编号的文件夹排最前。
  • 自动重新编号：所在文件夹统一重排、文字保留。
  • 自动命名：110.txt → 110-第一行文字.txt（超 16 字截断）。

草稿 / 素材

  • 名字以 _ 开头（兼容 [草稿]、draft-）即被视为草稿：草稿可编辑可搜索，但不参与阅览导出；
  • 点击隐藏文件按钮快速切换状态。

四种模式

  • 编辑：左写右预览，自动保存；预览：单独预览当前文件。
  • 阅览：全文件夹合并成书，左侧目录先文件名、再文内标题。
  • 大纲：卡片纵览全书，拖卡片调序/移入文件夹，编号自动重排。

写作辅助

  • 图片：粘贴/拖入自动存 assets 并插入，语法 ![](路径 =600x400 center)，宽高可只写一个；表格：表格内浮出工具条增删行列；调色盘：选色插入色值；全角空格：插入中文空格。
  • ◀/▶：按目录顺序切换文件（草稿除外）；搜索：全文查找，点结果跳转，Esc 或 ✕ 清空。
  • 替换：可选单文件或全项目 md/txt（含草稿需确认），替换前自动存「历史版本」。
  • 注释：<!--注释--> 仅编辑可见，阅览/PDF/导出 HTML 不显示（导出 MD 保留）。
  • 合并：Ctrl+点选多文件，内容并入第一个、其余删除；多选后拖动/删除/复制/隐藏均按组操作。
  • 拆分：按光标/标题/关键词拆分，原文件保留原名存前半，后续 base_2.txt、base_3.txt…（排序原文件在前）；目标名已占用时编号自动顺延并确认后创建；目录树可拖动移动，拖到项目名=移到根目录。

输出

  • 导出 PDF：阅览预览后点导出，打印目标选「另存为 PDF」。
  • 导出 MD：合并为一个 Markdown 下载（名带日期），可在 Typora 转 PDF。
  • 导出 HTML：单文件含左侧目录和自定义样式（名带日期），双击即可浏览器阅读。

回收站与历史

  • 删除/合并的文件进项目内 .trash，可恢复或清空；
  • 自动保存有变化时旧内容存 .history（按路径镜像），每文件留 20 版，可查看恢复；
  • 重命名/移动时历史自动跟随，恢复重名加「(恢复 n)」后缀；批量替换前自动留档。
  • 移入回收站历史保留；彻底删除/清空回收站才连历史清除、不可恢复，普通删除可找回。
  • .trash/.history 文件夹在工具内自动隐藏。
  • 建议定期复制整个项目文件夹备份。
