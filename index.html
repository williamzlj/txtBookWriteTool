为什么选择 txtBookWriteTool

不是又一个臃肿的写作平台——专注做好一件事：让长篇写作高效、安全、随心所欲。

📄

单文件运行

一个 HTML 文件，双击即开。无需安装、无需依赖、无需联网。拷到 U 盘就能带走。

🔒

数据全本地

所有内容都是你文件夹里的纯文本文件。不联网、不上传、无锁定。备份 = 复制文件夹。

📚

文件夹即项目

选一个文件夹就是一本书。txt/md 文件自动按编号排序，文件夹可分卷，结构一目了然。

📦

导出即用

合并成书后一键导出 PDF（含封面目录页码）、独立 HTML 或 Markdown，交付无忧。

功能一览

为长篇写作者量身打造的每一个细节。

✏️

四种工作模式

编辑 / 预览 / 阅览 / 大纲，一键切换，各司其职。

🔢

智能编号

三位数字 +10 增量，随时插入新章节不重排。

📝

草稿管理

下划线前缀标记草稿，可编辑搜索但不导出。

🖼️

图片即贴即用

粘贴拖入自动存 assets/，支持尺寸和对齐语法。

🔍

全局搜索替换

跨文件搜索，替换前自动存历史版本。

🔀

合并与拆分

多文件合并、按标题/关键词拆分，灵活重组。

🎨

样式定制

配色预设、字体选择、书主题、自定义 CSS。

📋

成书排版

封面、目录、页眉页脚、标题编号、首行缩进。

♻️

版本恢复

回收站 + 40 版历史，误删误改随时找回。
